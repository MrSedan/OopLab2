# Skills

Add reusable multi-step workflows here.

Expected structure:

```
.agents/skills/<skill-name>/SKILL.md
```

Use this directory for:
- real workflows with decision points
- repeatable operational procedures
- task-specific playbooks worth reusing across sessions

Do not use this directory for:
- single commands already visible in package scripts
- one-off notes
- facts that belong in knowledge or rules
